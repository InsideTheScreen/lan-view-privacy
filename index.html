LAN View privacy statement

Version: 2026-10-27-beta1. Prepared October 27, 2026.

LAN View is an independent experimental application for viewing normal gameplay from a console you own or are authorized to use. Live Xbox compatibility, streaming-service authorization and enforcement outcomes have not been certified. A published privacy statement is not Microsoft approval.

Maintainer and contact

Project maintainer: InsideTheScreen. For privacy questions, use the LAN View privacy repository's Issues page. Issues are public: do not post passwords, account tokens, payment details, private logs or other sensitive personal information. Ask the maintainer to arrange an appropriate private contact route before supplying personal details.

Information the app uses

The app reads its own local configuration, including the public privacy-page URL and the public application identifier you enter. The native process checks this published page at startup and approximately every five minutes while the app is open, comparing it to the bundled policy. These ordinary HTTPS requests disclose the requesting internet address and generic client/request metadata to GitHub and its delivery providers. No account tokens, console identifiers or gameplay are included in a privacy-page request.

Only when you choose Microsoft sign-in, the native process sends your configured application ID and Xbox sign-in scopes to Microsoft. You enter your password and complete verification on Microsoft's site; LAN View does not receive your password. Microsoft may issue access, refresh, Xbox and streaming-service tokens. LAN View uses them to request your associated consoles and to establish, maintain and end the selected home-streaming session. This involves console names/identifiers, service region/session identifiers and media negotiation information, including network addresses.

Authentication and session signaling use Microsoft's internet services. The LAN media only option filters media candidates; it is not a system firewall or proof of complete isolation. Video and audio are received and decoded for playback. LAN View does not record gameplay, use your microphone/camera, send gameplay controls or intercept another application's traffic.

Storage, disclosure and security

Application-managed account tokens stay in native-process memory. They are not saved to application token files, exported to the local viewer page, sent to this privacy website or included in generated receiver-check reports. Sign-out and exit drop the app's token references. This does not securely erase every Windows memory, paging or crash-dump copy.

The app saves only its public privacy URL and your local notice-review preference in receiver-settings.json. The application ID entered in the current beta is not saved as an account credential. WebView2 uses a dedicated local Profile directory. Windows, WebView2 and Microsoft services may retain their own caches, diagnostics or service records. LAN View adds no advertising or analytics, does not sell this information, and has no OpenAI/ChatGPT API integration or AI account credentials. The software's normal operation does not make requests to OpenAI.

Necessary authentication/session information goes to Microsoft's endpoints, and necessary media-control messages go to the selected session. Microsoft describes its handling in the Microsoft Privacy Statement. GitHub describes visitor/request and issue information in the GitHub General Privacy Statement. GitHub Pages logs visitor IP addresses for security. This page has no forms, scripts, cookies set by the page, external fonts or advertising pixels.

Your controls and retention

  • Until the published policy matches the bundled version and you have reviewed the notices locally, the main receiver interface stays gated. No Microsoft sign-in request is automatic.
  • Stop releases local media and requests cleanup of this app's streaming session. Cancel/sign out cancels pending app work, requests session cleanup and drops authorization references.
  • Emergency shutdown is available during startup and use. It blocks new app work and ends the app and its own processes, with a bounded attempt at ordinary session cleanup. It cannot retract earlier requests, erase Microsoft's records, guarantee remote cleanup or guarantee protection from enforcement.
  • If a later policy-availability/content check fails, the beta stops its own activity and exits. You may correct the setup and relaunch. Successful checks are point-in-time checks, not a continuous uptime or legal-compliance guarantee.
  • Receiver-check reports are generated only from the local synthetic test and saved only when you choose Save report and a destination. They contain technical measurements, not gameplay recordings or account tokens. You control subsequent sharing and deletion.
  • Close LAN View before deleting its dedicated application folder, Profile, receiver-settings.json or saved reports to remove local data. Unrelated browser and Xbox data are not erased. Microsoft may retain consent/service records; manage account permissions through Microsoft.
  • For access, correction or deletion questions about any information you voluntarily shared with the maintainer, contact the maintainer using the route above. The app has no maintainer-operated account database. GitHub and Microsoft provide controls for data they independently hold.

Changes to this statement

Changes receive a new version and must be kept consistent with the app's bundled copy. A changed public page will fail the beta's exact-content check until the updated copy is bundled and reviewed. The repository provides a public change history. You do not need to publish your app, transcripts, screenshots or credentials to host this statement.
